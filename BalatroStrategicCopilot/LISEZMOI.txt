Balatro Strategic Copilot 1.0.7
================================

Copilote stratégique pour Balatro : il analyse, calcule, recommande et apprend.
Il ne joue JAMAIS à votre place.

Installation sans programme (PC protégé, sans Lovely ni Steamodded)
  Copier main.lua et Mods (dossier COPIER_DANS_AppData_Balatro de l'archive) dans
  %AppData%\Balatro\ ; voir LISEZ-MOI.txt à la racine de l'archive.

Installation (Windows)
  Le plus simple : dans le dossier extrait de l'archive, double-cliquer sur
  INSTALLER_COPILOT.bat (il vérifie et répare tout, puis confirme que le jeu charge le mod).
  À la main :
  1. Installer Lovely (winmm.dll dans le dossier du jeu) et Steamodded.
  2. Supprimer toute ancienne copie du mod (dossier ou .zip) dans %AppData%\Balatro\Mods\
  3. Glisser CE dossier "BalatroStrategicCopilot" (pas le .zip, pas le dépôt GitHub entier)
     dans %AppData%\Balatro\Mods\
     Ce fichier doit exister exactement ici :
       %AppData%\Balatro\Mods\BalatroStrategicCopilot\BalatroStrategicCopilot.json
     Un .zip déposé tel quel, ou un dossier rangé trop profond, est ignoré sans message
     par les anciennes versions de Steamodded.
  4. Lancer le jeu : un bandeau vert « actif » apparaît en haut de l'écran pendant l'intro
     puis 15 secondes au menu (rouge avec la cause en cas d'erreur).
     Aucun bandeau = le mod n'a pas été trouvé : revoir l'étape 3.
     Si AUCUN mod ne marche (pas de fenêtre « Lovely », pas de bouton Mods) : Lovely
     (winmm.dll) n'est plus dans le dossier du jeu, par exemple après une réinstallation
     du jeu. Le réinstaller (lanceur Balatro Multiplayer, ou docs/INSTALL.md étape 2).
     Les conseils s'affichent en partie. Touche C : panneau, V : détails, B : badges.

Désinstallation
  - Supprimer le dossier %AppData%\Balatro\Mods\BalatroStrategicCopilot
  - (optionnel) supprimer les données apprises : %AppData%\Balatro\BSC\

Documentation complète : README.md et dossier docs/ du dépôt du projet.
